# Security policy

Please report a vulnerability privately, through GitHub's
[private vulnerability reporting](https://github.com/cmeans/muse-android-bridge/security/advisories/new)
for this repository, not in a public issue or pull request.

Include what you found, how to reproduce it, and the app version
(`status report` shows it as `version=`, and so does the app's page in
Android Settings). You'll get an answer there.

Fixes go into `main`; only the newest version is supported. The threat
model the bridge is built to is in PROTOCOL.md §8.
